# Twin Embers HD battle scenes

The HD battle scenes that the [Twin Embers](https://github.com/alex61194/twin-embers) Builder can download: 62 scenes of
400x240 (`graphics/gen4/hdn/`), the same as 272x112 tile scenes (`graphics/gen4/hd/`) and the table of maps that picks
one (`graphics/gen4/hd/map.bin`), by day and by night. Files only: the Builder reads them at a pinned commit and checks
each one's size and SHA-256.

## Credit

The art is **HD Dynamic Battlefields, by Bentley734** (https://github.com/Bentley734/HD-Dynamic-Battlefields). These files are
his paintings cut and reduced to the 3DS's resolution by `tools/dev_hd_battlefields.py` in the Twin Embers repository. The
original paintings are not here.


The places and settings drawn belong to Nintendo, Game Freak and Creatures.
